# ロール一覧

概念設計ドキュメント（docs/concept/*.md）で使うロールの共通定義。
ロール名はここに書いたものを正とし、各ドキュメントで表記を揺らさない。

| ロール | 一文定義 | 関心事・使う語彙の例 |
|--------|---------|-------------------|
| ホスト | 企画（ロビー）を立て、募集・日程調整・選出・開催の管理を行う1人の主催者 | 卓を立てる、声かけ、募集、締め切り、候補枠を挙げる、選出、確定、リスケ、追加募集、開催の完了・中止、企画の解散 |
| 参加者 | ログインしてロビーに「遊びたい」と表明し、日程回答・着席・プレイをする人 | 参加する、◯△×で答える、着席、キャラクター名、プレイメモ、脱退、「自分は選ばれたのか」 |
| ゲスト参加者 | アカウントを持たず、招待リンク（トークン）経由で参加する本人確認手段のない参加者 | 招待リンク、名前だけで参加、（本人確認がないため）全ゲスト分の回答編集 |

- 「ホスト」は管理権限を持つロールであり、管理権限は LobbyEntry の有無に依存しない
  （design-v1.1 の意思決定ログを踏襲）。ただし通常、ホストは自分のロビーに自分の LobbyEntry を持ち
  （現行の「作成時にホストを自動追加」と同じ）、プレイヤーまたは進行役（GM）として着席できる。
- 「ゲスト参加者」は独立した概念ではなく、LobbyEntry の一状態（`userId = null`）である。
  ロールとしては語彙・操作経路（トークンヘッダー）が異なるため区別して扱う。

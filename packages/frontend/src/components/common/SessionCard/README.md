# SessionCard

卓（ゲームセッション）一覧の 1 アイテムを表示するシグネチャコンポーネント。

## Props

| 名前         | 型                                                 | 必須 | 既定           | 説明                                                             |
| ------------ | -------------------------------------------------- | ---- | -------------- | ---------------------------------------------------------------- |
| `title`      | `string`                                           | ✅   | —              | セッションのタイトル                                             |
| `dateLabel`  | `string`                                           | ✅   | —              | 開催日時のラベル                                                 |
| `location`   | `string`                                           | ✅   | —              | 開催場所                                                         |
| `status`     | `'recruiting' \| 'full' \| 'confirmed' \| 'ended'` | —    | `'recruiting'` | ステータス                                                       |
| `slotsLabel` | `string`                                           | —    | —              | 「あと 2 枠」など                                                |
| `members`    | `string[]`                                         | —    | —              | 参加者の表示名。頭文字をアバターに表示（最大 4 件、超過分は +N） |
| `tag`        | `string`                                           | —    | —              | シナリオ種別など                                                 |

## Emits

- `click`: カード全体クリック時に発火

## 単体テスト項目

- タイトル・日時・場所が表示される
- デフォルトは status=recruiting のバッジになる
- status 別にラベルが切り替わる
- members でアバターが表示される
- 4 件を超えると +N オーバーフローが出る
- click イベントが emit される

# 用語集（CONTEXT）

このリポジトリで使う語彙の索引。**一文定義と、利用者に見せる表記だけ**を置く。

- **会話・コード・ドキュメントにこの表と食い違う言葉が出てきたら、その場で指摘する。**
  決着したらこのファイルを更新する（`concept-design` スキルの担当）
- テーブル・カラム・API の詳細は書かない → [`docs/design/v0.3/design-concept-model.md`](../design/v0.3/design-concept-model.md)
- 概念の責務・持たないものの詳細も書かない → `docs/concept/*.md`

## 概念

| 概念 | 一文定義 | UI 表記 |
|---|---|---|
| Lobby | 「このシナリオをこの面々で遊ぼう」という、開催を重ねても継続する企画 | 卓 |
| LobbyEntry | 「この企画に加わる」という表明。開催をまたいで続く | 参加 / 参加者 / メンバー |
| SchedulePoll | 候補日を挙げて◯△×を集める一回の調整。ロビーに 0..n 回起きる | 日程調整 |
| CandidateDate | ある日程調整に挙げられた1つの候補日（1日1枠） | 候補日 |
| ScheduleAnswer | ある参加者による、ある候補日への◯△×の表明 | 回答 |
| GameSession | 「この日にこの顔ぶれで開く」一回の開催。ロビーに 0..n 個 | 卓（開催を区別する必要がある画面でだけ「開催」） |
| Seat | ある開催にある参加者が着くこと。選出の結果はこれの有無で表される | 着席 / 当日の参加者 |
| CharacterAssignment | ある着席者がその開催で誰を演じるかの割り当て | キャラクター名 |
| PlayMemo | 着席者がその開催に残す自分の記録 | プレイメモ |

詳細は [`lobby-game-session.md`](./lobby-game-session.md) の概念一覧。

## 卓の状態

利用者に見せるのはこの1系列だけ。**固定語彙なのでそのまま使う。**

```
募集中(recruiting) → 調整中(adjusting) → 開催予定(scheduled) → 完了(completed) / 中止(cancelled)
```

下書き(draft) はこの系列の外で、ホストにしか見えない。
定義は `packages/frontend/src/features/GameSession/gameSessionCardStatus.ts`。

## 紛らわしい語

| 対比 | 違い |
|---|---|
| 卓 / ロビー / 開催 | UI では Lobby と GameSession を「卓」1つに畳む。**「ロビー」は UI に出さない**（コード側の型名としては使う）。複数回の開催を区別する必要がある画面でだけ「開催」を使う |
| 解散(disbanded_at) / 中止(cancelled_at) | 解散は**企画そのもの**を畳むこと（Lobby）。中止は**1回の開催**をやめること（GameSession）。別テーブルの別カラム |
| 参加(LobbyEntry) / 着席(Seat) | 参加は企画に加わる表明で、開催をまたいで続く。着席は1回の開催に出ること |
| 確定 | 状態としては存在しない。日程が決まる＝GameSession が生まれること |
| 募集 | 独立した概念ではない。Lobby の `published_at` / `open_until` / `reception_closed_at` の組み合わせ |

> `docs/design/v0.3` §2-2 の日本語ラベル表は issue #147 より前のもので、Lobby を「ロビー」、
> GameSession を「開催 / セッション」としている。**UI 表記の正はこのファイル**であり、
> §2-2 は改名の履歴として読む。

## ロール

| ロール | 一文定義 | 関心事・使う語彙の例 |
|---|---|---|
| ホスト | 企画（ロビー）を立て、募集・日程調整・選出・開催の管理を行う1人の主催者 | 卓を立てる、声かけ、募集、締め切り、候補枠を挙げる、選出、確定、リスケ、追加募集、開催の完了・中止、企画の解散 |
| 参加者 | ログインしてロビーに「遊びたい」と表明し、日程回答・着席・プレイをする人 | 参加する、◯△×で答える、着席、キャラクター名、プレイメモ、脱退、「自分は選ばれたのか」 |
| ゲスト参加者 | アカウントを持たず、招待リンク（トークン）経由で参加する本人確認手段のない参加者 | 招待リンク、名前だけで参加、（本人確認がないため）全ゲスト分の回答編集 |

- **ホスト**は管理権限を持つロールであり、管理権限は LobbyEntry の有無に依存しない
  （design-v1.1 の意思決定ログを踏襲）。ただし通常、ホストは自分のロビーに自分の LobbyEntry を持ち、
  プレイヤーまたは進行役（GM）として着席できる
- **ゲスト参加者**は独立した概念ではなく、LobbyEntry の一状態（`userId = null`）である。
  ロールとしては語彙・操作経路（トークンヘッダー）が異なるため区別して扱う
